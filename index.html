⚙️ 서버 상태 확인 중...
1
Python 설치
컴퓨터에 한 번만 하면 됩니다
✅ 완료
⬇ Python 다운로드 (클릭)
설치할 때 꼭! 아래 체크박스를 선택하세요:
☑ "Add Python to PATH" (하단에 있음)
2
서버 시작
항상 켜두는 컴퓨터에서 실행
✅ 연결됨
1. 받은 파일 중 지양하월시아_서버 폴더를
   원하는 위치에 저장 (예: 바탕화면)
2. 폴더 안의 서버시작.bat 더블클릭
3. 검은 창이 뜨고 서버 시작! 글자 보이면 완료
💡 검은 창(서버)은 닫지 마세요. 최소화만 해두세요.
3
📱 MacroDroid 설정
입금 문자 → 서버 자동 전송
⚠️ 먼저 2단계(서버 시작)를 완료하면 아래 값들이 자동으로 채워집니다.
구글 플레이에서 MacroDroid 설치 후, 아래 순서대로 진행하세요.
① 앱에서: 매크로 추가 → 이름 입력
입금알림전송
② 트리거 → SMS 수신 → 내용 필터
입금
(농협, 국민 두 개 만들어도 되고, 하나로 해도 됩니다)
③ 액션 → HTTP 요청 → URL 붙여넣기
로딩 중...
④ 방법(Method)
POST
⑤ 헤더 → 추가: Key / Value
Content-Type
application/json
⑥ 바디(Body) → 아래 전체 복사 후 붙여넣기
{"body": "[%SMSBODY%]", "sender": "[%SMSNAME%]", "time": "[%SMSTIME%]"}
설정 완료 후 → 테스트
버튼을 누르면 가짜 입금 데이터를 서버에 전송해서 정상 작동하는지 확인합니다.
