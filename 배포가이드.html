🌿 웹사이트 배포 가이드

직원들이 어디서든 접속 가능한 웹페이지 만들기 · 약 10분 소요

1

GitHub 가입 · 파일 올리기

코드를 인터넷에 저장하는 공간 (무료)

1
🐙 GitHub 가입하기
2
가입 후 → New repository 클릭
이름: haworthia 입력 → Create repository
3
💻 GitHub Desktop 설치
GitHub Desktop은 파일 업로드를 마우스로 쉽게 할 수 있는 프로그램이에요.
4
GitHub Desktop 실행 → File → Add Local Repository
→ 지양하월시아_서버 폴더 선택
→ Publish repository 클릭
2

Railway 배포

클라우드 서버에 올리기 (무료 · 24시간 운영)

1
🚂 Railway 가입하기
→ "Login with GitHub" 클릭 (GitHub 계정으로 바로 가입)
2
로그인 후 → New Project 클릭
→ Deploy from GitHub repo 선택
→ haworthia 선택
3
자동으로 배포 시작 — 1~2분 기다리면 완료
→ Settings → Networking → Generate Domain 클릭
→ haworthia-production.up.railway.app 같은 주소 생성됨
💡 이 주소를 직원들에게 공유하면 끝이에요. PC가 꺼져도 24시간 작동합니다.
3

MacroDroid SMS 주소 업데이트

입금 문자 수신 주소를 새 서버로 변경

1
MacroDroid 앱 → 입금알림전송 매크로 → 액션 → HTTP URL 수정
기존: http://192.168.x.x:5000/sms
변경: https://[Railway주소]/sms
⚠️ Railway 주소를 받은 뒤에 변경하세요. 웹페이지 ⚙️ 초기설정 탭에 정확한 주소가 자동으로 표시됩니다.
✅ 완료! 이제 직원들은 Railway 주소만 북마크하면 어디서든 접속 가능합니다.
